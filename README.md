# Recipe page

My solution to the [Recipe page challenge on Frontend Mentor](https://www.frontendmentor.io).

## Links

- Live site: https://github.com/theint-hub/recipe-page.git
- Repository: https://github.com/theint-hub/recipe-page

## Built with

- Semantic HTML5
- CSS custom properties (variables)
- Mobile-first workflow
- Google Fonts (Outfit and Young Serif)

## What I learned

- Using semantic elements like `main`, `section` and `th scope="row"`
- Organizing colors with CSS variables
- Making a flexible layout with `max-width` and one media query
